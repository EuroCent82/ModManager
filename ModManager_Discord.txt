Developer note - Unofficial community mods

The mods and links in this thread are shared by their creator. We don’t review or test these files and can’t verify their safety or compatibility. Any Discord server linked here is run independently from the studio.

Back up your saves before installing any mods. Mods can corrupt your save files or prevent the game from launching, even if they worked before a game update. We can’t recover corrupted saves or fix issues caused by mods.

**Mod Manager** adds a **Mod-Manager** tab after Keyboard in the Pionero Capital settings. It is a PineLoader mod. Labels follow the language of the game.

**1.0.2** needs **PineLoader 1.1.0-alpha**.

Each loaded mod gets the same on/off bar the game uses for VSync, and a key row that uses the game’s own key button. Glovebox does not need this mod. Without it, Glovebox still reads its ini and still opens on its key.

A switch for **right now** writes `Running` and leaves `Enabled` as it was. A switch for the **next start** writes `Enabled`. The menu log is `Logs\mod-manager.txt`.

**Install**
Close the game. Copy the `ModManager` folder from the zip into `PineLoader\Mods`. The zip has no pak. The mod writes the tab when it runs. If the tab is missing the first time, start once through PineLoader, then open Settings again.
